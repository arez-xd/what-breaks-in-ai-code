# Example requests

## Your latest changes

```text
Review my changes before I push.
```

```text
I asked Cursor to add Stripe checkout. Check what it changed before I commit.
```

```text
Review the last three commits.
```

## A pull request or a branch

```text
Review PR #42.
```

```text
Review this branch against main. The author says validation is handled upstream.
```

```text
A contractor sent this diff. Is it safe to merge?
```

## A whole app

```text
I built this app with an AI agent and want to launch on Monday. Is it safe to ship?
```

```text
Review the whole project. We're giving it to our first ten customers next week.
```

```text
Is anything in this repo exposing our keys or our users' data?
```

```text
Our support chat shows the model's answers as markdown. Check it before we launch.
```

## More or less

```text
Review my changes, nits too.
```

```text
The agent wrote this module and it feels bloated. What could be simpler?
```

```text
Only the payments code, please.
```

```text
Explain the findings for someone who doesn't code.
```
